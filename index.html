How it works: the PO lines and the CBD costs are matched to each BOM row by item type, colour and size. A value is filled only when exactly one PO item matches. Anything unclear is marked for checking and left unchanged.

    
The Excel file has five sheets: New (Filled), Change Log, PO Lines, CBD Data and Checks. If the Checks sheet says FAIL, do not trust the run.

    
The first visit on a computer loads the engine (about 14 MB, then the browser keeps it). A 30 page PO takes about one minute.

    
Built with Pyodide, pdfplumber, pdfminer.six, openpyxl, xlrd and charset-normalizer (open-source; their licences ship with the tool files, Pyodide is MPL-2.0).
